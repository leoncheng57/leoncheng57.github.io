# Run simulator

A toy model of one manager agent dispatching parallel workers. Step through a guided run to see the moving parts, then tune the knobs to see where time goes, where work stalls waiting on a human, and which moments are yours versus the agents'.

This simulator is experimental and deliberately simplified: durations are simulated minutes, not measurements. The same seed always replays the same run.
